# Questlords-GAME
An alpha open source game

Development started: Sunday, 24 July 2016

## QuadCOM desk

`quadcom/` holds the QuadCOM 2000-PICO trading desk (V45). It includes the GLIMMER
hardware compute governor (WebGPU → WebGL2 → Wasm SIMD / workers → JS), the GLIMMER
VISION render view and the AURUM texture pack. Launch it with
`python3 quadcom/quadcom.py` and see `quadcom/V44_GLIMMER_NOTES.txt` and `quadcom/V45_VISION_NOTES.txt`.
