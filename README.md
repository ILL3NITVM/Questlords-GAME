## QuadCOM desk

`quadcom/` holds the QuadCOM 2000-PICO trading desk (V44). It includes the GLIMMER
hardware compute governor: WebGPU → WebGL2 → Wasm SIMD / workers → JS. Launch it with
`python3 quadcom/quadcom.py` and see `quadcom/V44_GLIMMER_NOTES.txt`.
